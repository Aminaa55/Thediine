# Brand assets

## the-diine-logo.png (or .svg) — NOT YET SUPPLIED

Drop the official logo file here and set `LOGO_SRC` in `src/lib/brand.ts` to its
path. The header and footer pick it up immediately.

The logo has deliberately **not** been recreated, redrawn or approximated. Until
the real file is here, the header and footer show the name set in the brand
typeface only.

An SVG is best — it stays sharp at every size. A PNG of at least 1000px wide,
with a transparent background, also works.
