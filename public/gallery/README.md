# Our Work photographs

Real photographs of The Diine's dishes, tables and events.

These are managed from the admin dashboard, not from this folder — each image is
a `GalleryImage` row with its own alt text, caption, placement and sort order, so
they can be added, removed and reordered without a developer.

This folder is only the storage location while the project runs locally. In
production the images live in cloud storage and `GalleryImage.imageUrl` points
at them.

**No photographs are committed yet.** The "Our Work" section is built and hides
itself when there are none, so customers never see empty frames.
